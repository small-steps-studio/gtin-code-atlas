# Getting started

1. Install **GTIN Code Atlas** (publisher SmallStepsStudio) from the Extensions view.
2. Open a text file with GS1 element strings, barcode data or GTINs (one per line), or run **GTIN Code Atlas: Open Sample File** to open the invented sample.
3. Open the Command Palette (`Ctrl+Shift+P`, on macOS `Cmd+Shift+P`), type `GTIN Code Atlas` and pick a report. The button in the editor title bar of *.txt and *.csv files runs **Show Element String Check**.
4. The report opens as a new Markdown document (and its preview). Save it, copy it into a ticket, or close it.
5. **GTIN Code Atlas: Open Walkthrough** shows the same steps inside the editor.

Every report is described in [reports.md](reports.md). Licence and trial: [licence.md](licence.md). Problems: [troubleshooting.md](troubleshooting.md).
