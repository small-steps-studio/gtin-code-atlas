# Pro reports

* **Show Digital Link Conversion**: The GS1 Digital Link web address for each valid element string.
* **Show GTIN And Serial Inventory**: Lots and serial numbers per GTIN, and serial numbers that appear more than once.

The first Pro command starts a free 14-day trial on this computer. After the trial, Pro is a one-time purchase: USD 19 (Personal) or USD 39 per user (Business).
