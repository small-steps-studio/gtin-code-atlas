# Open a sample file

GTIN Code Atlas reads one code per line: GS1 element strings in brackets such as (01)09506000134352(17)271231, raw scanner data with group separators, GS1 Digital Links, and bare GTIN or SSCC numbers. The sample is an invented warehouse list with one wrong check digit and a duplicate serial, so every report has something to show.

The sample is invented data. Open one of your own files at any time instead.
